## Proposition 5.15
**Statement:** Parts have the same ratio as the same multiples of them taken in corresponding order.

**Step 1.** Let C and D be the same multiples of A and B, respectively. By the meaning of a multiple, write
C = A₁ + ⋯ + Aₙ and D = B₁ + ⋯ + Bₙ,
where every Aᵢ equals A and every Bᵢ equals B. We must prove A : B = C : D. [D5.2]

**Step 2.** For each i, since Aᵢ = A, equal magnitudes have the same ratio to Bᵢ; hence Aᵢ : Bᵢ = A : Bᵢ. Since Bᵢ = B, the same magnitude A has the same ratio to them; hence A : Bᵢ = A : B. Therefore Aᵢ : Bᵢ = A : B for every i, so all the corresponding pairs of parts are proportional. [5.7, 5.11]

**Step 3.** Apply Proposition 5.12 directly: its rule for collecting antecedents and consequents is the natural route here because the multiples are exactly those collected sums. It gives
A₁ : B₁ = (A₁ + ⋯ + Aₙ) : (B₁ + ⋯ + Bₙ) = C : D.
Together with Step 2, this yields A : B = C : D. Thus parts have the same ratio as the same multiples of them taken in corresponding order. [5.12, 5.11]
