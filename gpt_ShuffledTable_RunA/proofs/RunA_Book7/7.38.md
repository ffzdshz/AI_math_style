## Proposition 7.38
**Statement:** If a number have any part whatever, it will be measured by a number called by the same name as the part.

**Step 1.** Let A have a part B, and let C be the number called by the same name as that part. Thus A consists of as many copies of B as there are units in C. If B is a unit, then C equals A and measures A once, so the conclusion already holds. Otherwise B is a number. [D7.1, D7.2, D7.3]

**Step 2.** We take the direct multiplication route, since it allows the roles of B and C to be interchanged. By the definition of multiplication, C multiplying B produces A. [D7.15]

**Step 3.** The numbers produced by two numbers multiplying one another are equal. Therefore B multiplying C also produces A. [7.16]

**Step 4.** Consequently A consists of as many copies of C as there are units in B. Hence C measures A; and C is precisely the number called by the same name as the given part. Therefore, if a number has any part whatever, it is measured by the number called by the same name as that part. [D7.15, D7.3]
