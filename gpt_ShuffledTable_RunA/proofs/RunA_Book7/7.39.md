## Proposition 7.39
**Statement:** To find the number which is the least that will have given parts.

**Step 1.** Let the given parts be named by the numbers a₁, …, aᵣ: thus aᵢ names the aᵢ-th part. By VII.37, a number measured by every aᵢ has all the given parts; conversely, by VII.38, any number having all those parts is measured by every aᵢ. We therefore seek their least common multiple. We use successive two-number constructions, since this directly accommodates any finite list of given parts. [7.37, 7.38]

**Step 2.** Put L₁ = a₁. For each i from 2 through r, construct Lᵢ as the least number measured by Lᵢ₋₁ and aᵢ, using VII.34. Every aⱼ with j ≤ i measures Lᵢ: the earlier naming numbers measure Lᵢ₋₁, which measures Lᵢ, and aᵢ also measures Lᵢ. Consequently all the naming numbers measure L = Lᵣ, so L has every given part by VII.37. [7.34, 7.37]

**Step 3.** Let N be any number having every given part. Each aᵢ measures N by VII.38. Thus L₁ measures N. Whenever Lᵢ₋₁ measures N, both Lᵢ₋₁ and aᵢ measure N; therefore their least common multiple Lᵢ also measures N, by VII.35. Successively, L measures N. A number cannot be smaller than a number which measures it, so N is not smaller than L. Hence L has the prescribed parts and is the least number that has them, as required. [7.38, 7.35]
