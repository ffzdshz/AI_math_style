# 倒序子表对照实验：运行与边界

## 实验定义

独立工程，以已完成的 `euclid-proof-project-shuffled-table` Run A 为对照。对于每一命题，先把 `data/Euclid_All_Statements.xlsx` 的**数据行**倒转（表头保留在第一行），再排除所有不允许引用的条目。此顺序等价于先筛选后倒转，绝不是按编号字符串或数值排序，也不再随机打乱。保留全部基础条目和严格早于目标的定理；目标和后续定理排除。不同物理重试的同一命题表行顺序相同。

目标集、基础规则、工作流与用户可见的 prompt/tool 指令不变。机器检查了 465 个目标的首次及带违规反馈重试 prompt 字节哈希、所有允许集合、worker 指令与工具 schema，与乱序工程一致。真实准备样例 6.10 的表包含 291 条；行顺序确实为倒序筛选，允许集合一致，prompt、AGENTS、MCP server 逐字节一致。`shuffle_seed` 是继承的内部兼容字段，本实验**不使用它决定表顺序**。

每卷先全部初稿、再最多三轮越序重证，冻结后才读取人类引用。输出原有的整卷证明 MD、AI/人类引用 CSV、执行元数据及逐命题 MD；不判断数学正确性。模型均请求 `gpt-6-astra / xhigh`，最多 4 并发、启动间隔 30 秒，无模型降级。后台守护器一旦发现执行异常将保留已接受尝试并按规则恢复；不能确认代理配置及模型时保守阻塞。不会自动消费任何重置卡，先前一次性授权不适用于本轮。

## 校验与限制

- 离线测试：`docs/REVERSE_OFFLINE_TESTS.txt`；无真实模型调用。prepare-only 目录 `runs/RunReversePrepareCheck_Book6_Smoke_6.10-6.10/` 仅用于验证，不属于正式结果。
- 保存结果审计除了资源集合与哈希外，还独立按原 Excel 原始物理行重算倒序，以验证真实 XLSX 行顺序；没有只相信侧车 metadata。
- 相较乱序工程，本实验可控制提示词与信息资源集合，但不同时间的模型服务、网络、额度、输出等仍可能改变结果。不得将观察性差异自动解释为行序的因果作用；上游实际权重不独立鉴证。
