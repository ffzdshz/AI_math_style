## Proposition 7.5
**Statement:** If a number be a part of a number, and another be the same part of another, the sum will also be the same part of the sum that the one is of the one.

**Step 1.** Let A be a part of B, and let C be the same part of D. Thus B consists of some number n of groups each equal to A, and D consists of the same number n of groups each equal to C, where n is at least two. Denote these groups by B₁, …, Bₙ and D₁, …, Dₙ respectively. We use these groups directly, rather than introduce proportions. [Hypothesis; D7.3]

**Step 2.** Pair each group Bᵢ with the corresponding group Dᵢ. Since Bᵢ equals A and Dᵢ equals C, their sum Bᵢ + Dᵢ equals A + C. Thus each of the n paired groups equals A + C. [CN2]

**Step 3.** These n paired groups contain precisely all the units of B together with all the units of D, each occurring once. Their whole therefore coincides with, and equals, B + D. Consequently B + D consists of n groups each equal to A + C. [D7.2; CN4; Step 2]

**Step 4.** Hence A + C measures B + D exactly n times. Since n is at least two, A + C is less than B + D, and is therefore a part of it. Since A likewise measures B exactly n times, A + C is the same part of B + D that A is of B, as required. [CN5; D7.3; Steps 1 and 3]
