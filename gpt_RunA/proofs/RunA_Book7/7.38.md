## Proposition 7.38
**Statement:** If a number have any part whatever, it will be measured by a number called by the same name as the part.

**Step 1.** Let A be a number having a part B, and let u be a unit. Let N be the number called by the same name as that part: thus B is an N-th part of A, meaning that the equal copies of B making up A are as many as the units composing N. Hence B measures A the same number of times that u measures N. [D7.1, D7.2, D7.3]

**Step 2.** If B is a unit, A and N consist of equally many equal units. Adding these units gives A = N, so N measures A once. [D7.1, D7.2, CN2]

**Step 3.** Otherwise B is a number. Apply 7.15 directly; this is the natural route because Step 1 supplies precisely its equal-count hypothesis. Since u measures N the same number of times that B measures A, alternately u measures B the same number of times that N measures A. Consequently N measures A. Thus, in either case, A is measured by the number called by the same name as its given part, as required. [7.15; Steps 1–2]
