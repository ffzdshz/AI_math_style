## Proposition 7.29
**Statement:** Any prime number is prime to any number which it does not measure.

**Step 1.** Let A be a prime number, and let B be a number which A does not measure. We use the direct common-measure route: primality restricts the measures of A, while being prime to B is defined by their common measures. [D7.11, D7.12]

**Step 2.** The unit measures both A and B, since each number is a multitude composed of units. [D7.2]

**Step 3.** Suppose that a number C greater than the unit measures both A and B. Since A is prime, C cannot be a measure smaller than A; consequently C must be A itself. But C measures B, so A would measure B, contrary to the hypothesis. Thus no number greater than the unit measures both A and B. [D7.11; hypothesis]

**Step 4.** Therefore A and B have the unit alone as a common measure, and hence are prime to one another. Thus any prime number is prime to any number which it does not measure. [Steps 2–3; D7.12]
