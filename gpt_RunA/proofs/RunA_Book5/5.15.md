## Proposition 5.15
**Statement:** Parts have the same ratio as the same multiples of them taken in corresponding order.

**Step 1.** Let A and B be the parts, and let M and N be the same multiples of A and B respectively. By the definitions of part and multiple, write M = A₁ + ⋯ + Aₙ and N = B₁ + ⋯ + Bₙ, with the same number of terms, where every Aᵢ equals A and every Bᵢ equals B. We must prove A:B = M:N. [D5.1, D5.2]

**Step 2.** For each corresponding pair, Aᵢ:Bᵢ = A:Bᵢ because Aᵢ = A, and A:Bᵢ = A:B because Bᵢ = B. Therefore Aᵢ:Bᵢ = A:B for every i: all the corresponding pairs have the same ratio. [5.7, 5.11]

**Step 3.** Apply 5.12 directly: this is the natural route because the multiples are already expressed as equally numerous lists of proportional parts. As one antecedent is to its consequent, so are all the antecedents together to all the consequents together. Hence A₁:B₁ = (A₁ + ⋯ + Aₙ):(B₁ + ⋯ + Bₙ) = M:N. [5.12]

**Step 4.** By Step 2, A:B has the same ratio as A₁:B₁; by Step 3, M:N also has that ratio. Therefore A:B = M:N. Thus parts have the same ratio as the same multiples of them taken in corresponding order. [5.11]
