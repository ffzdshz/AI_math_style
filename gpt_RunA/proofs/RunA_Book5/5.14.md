## Proposition 5.14
**Statement:** If a first magnitude have to a second the same ratio as a third has to a fourth, and the first be greater than the third, the second will also be greater than the fourth; if equal, equal; and if less, less.

**Step 1.** Let A, B, C, D be the first, second, third, and fourth magnitudes, with A:B = C:D. [Hypothesis.] Path choice: for the strict comparisons, use ratios with a common term—first 5.8, then 5.13 to transfer the comparison, and finally 5.10 to compare the magnitudes.

**Step 2.** Suppose A > C. Then A:B > C:B, since the greater magnitude has to the same a greater ratio than the less has. [5.8.] But C:D = A:B by the hypothesis; therefore C:D > C:B. [5.13.] Of magnitudes to which the same magnitude has a ratio, that to which it has the greater ratio is less. Hence D < B, that is, B > D. [5.10.]

**Step 3.** Suppose A = C. Equal magnitudes have to the same the same ratio, so A:B = C:B. [5.7.] Together with the hypothesis A:B = C:D, this gives C:B = C:D, since ratios which are the same with the same ratio are the same with one another. [5.11.] Therefore B = D, since magnitudes to which the same has the same ratio are equal. [5.9.] Here the direct equality criterion is used rather than excluding the two strict inequalities.

**Step 4.** Suppose A < C. Then C:D > A:D, since the greater magnitude has to the same a greater ratio than the less has. [5.8.] Since A:B = C:D by the hypothesis, it follows that A:B > A:D. [5.13.] Thus B < D, since that to which the same magnitude has a greater ratio is less. [5.10.]

**Step 5.** Consequently, when the first magnitude is greater than, equal to, or less than the third, the second is respectively greater than, equal to, or less than the fourth. [Steps 2–4.] This proves the proposition.
